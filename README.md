# Slide 15 · Neon Number Puzzle

Free single-file HTML5 sliding number puzzle. Scrambled neon tiles, three
grid sizes (3×3 / 4×4 / 5×5), always-solvable shuffles, smooth slide
animation and a glowing win celebration. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/slide-15/

- Tap / click any tile in the empty slot's row or column to push the whole
  line, or slide tiles next to the gap with the arrow keys
- Shuffles made of random legal moves from the solved board — every puzzle
  is guaranteed solvable (60 / 150 / 300 scramble steps by grid size)
- Move counter + timer, per-size best records (moves, then time) saved
  locally, mute toggle
- Procedural WebAudio sounds, procedural neon visuals, no dependencies,
  no tracking
